# C Programming Exercises

Welcome to the **C Programming Exercises** repository!  
This collection is designed to help beginners and intermediate learners strengthen their understanding of the C programming language through hands-on practice.

## 📂 Repository Structure

Each exercise is organized in its own `.c` file. The exercises cover a variety of fundamental and advanced topics, such as:

- ✅ Variables and Data Types  
- 🔁 Loops and Conditionals  
- 🧠 Functions  
- 📚 Arrays and Strings  
- 🧩 Pointers and Memory Management  
- 🗂️ Structures and Files  
- 📈 Algorithms and Logic Problems  

> 🚧 New exercises will be added continuously. Stay tuned!
